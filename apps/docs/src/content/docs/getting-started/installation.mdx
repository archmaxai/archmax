## Docker Compose (Recommended)

The fastest way to run archmax is with Docker Compose. This starts archmax with dedicated MongoDB and Redis services:

```bash
git clone https://github.com/archmaxai/archmax.git
cd archmax
cp .env.example .env
```

Edit `.env` and set the required values:

```bash
BETTER_AUTH_SECRET=$(openssl rand -base64 32)
UI_PASSWORD=your-secure-password
AGENT_API_KEY=your-api-key
```

Then start the stack:

```bash
docker compose up -d
```

Open `http://localhost:8080` and log in with username `admin` and the password you set.

<Aside type="tip">
The Compose stack runs MongoDB and Redis as separate containers alongside archmax. Project data is stored in the `archmax-data` volume and MongoDB data in `mongo-data`.
</Aside>

## Standalone Docker

Run archmax as a single container with no external dependencies — MongoDB and Redis are embedded:

```bash
docker run -d \
  --name archmax \
  -p 8080:8080 \
  -e BETTER_AUTH_SECRET=$(openssl rand -base64 32) \
  -e UI_PASSWORD=changeme \
  -v archmax-data:/app/data \
  archmax/archmax:latest
```

<Aside type="note">
MongoDB and Redis are both embedded in the image and start automatically when `MONGODB_URI` / `REDIS_URL` are not provided. To use external instances instead, pass `MONGODB_URI` and/or `REDIS_URL`. The volume mount at `/app/data` captures both project files and embedded MongoDB data.
</Aside>
